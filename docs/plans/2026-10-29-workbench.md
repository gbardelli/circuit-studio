# Circuit Studio workbench

The approved direction combines precise manipulation with integrated electrical inspection, timing analysis, circuit diagnostics, command search and physical assembly. Keep the established dark hardware workspace; strengthen hierarchy with a compact workbench rail, quieter sidebars, aligned measurements and a distinct mint trace color. Interaction feedback is local, interruptible and reduced-motion aware.

Move simulation into a module worker. The main thread receives visual and electrical samples while pointer movement remains independent. Record watched digital edges at solver boundaries and visual frames at a bounded rate. Historical inspection restores the displayed circuit at the selected instant; resuming from history reconstructs the simulation by replaying recorded inputs and document changes from the initial state in the worker. Topology changes create a new recording. Never claim hardware snapshots or native CPU reverse execution.

Diagnostics derive from actual nets, component pin metadata, measured voltages and current driver modes. Report only supported checks, expose evidence, and distinguish measured facts from possible causes. A command palette searches parts and actions and can connect an explicitly selected pin to a named target. No paid AI service or invented diagnosis is required.

Assembly provides ordered wire instructions, two highlighted endpoints, persistent completion, editable procurement costs, material export and a printable schematic/assembly document. Photos can be attached locally for side-by-side manual comparison; automated image recognition is outside the available backend. Component comments live in the existing collaborative Yjs document.

Validate signal capture, replay, conservative diagnostics, assembly persistence, commands, worker lifecycle, keyboard focus, reduced motion and responsive layout. Run the full test suite and production build, exercise the integrated browser flows, push and deploy the verified revision.
